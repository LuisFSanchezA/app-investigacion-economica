# Bitácoras diarias

Registro del trabajo diario del proyecto.

## Convención

- Un archivo por día trabajado: `YYYY-MM-DD.md`.
- Si un día no hay trabajo, no se crea archivo.
- Las bitácoras semanales antiguas (`bitacora_semana_*.md`) se conservan
  en `docs/` como referencia histórica.

## Plantilla

Copia `_plantilla.md` para empezar un día nuevo.
