## Objetivo del día
Completar la integración de INEGI como fuente de datos.

## Logros

1. **`src/fuentes/inegi.py`**:
   - Conector para la API de Indicadores del INEGI.
   - Catálogo de 5 indicadores (PIB, población, desocupación, inflación).
   - URL corregida: `BIE-BISE/2.0`, `area=0`, `recent=true`.
   - Parser tolerante: `OBSERVATIONS` (inglés), `COBER_GEO` para entidad.
   - **Fix importante**: filtrar siempre por entidad, incluido `"0"` (Nacional).
     Antes devolvía 33 filas; ahora devuelve 1.
2. **Prueba real**: 33 observaciones de PIB por entidad federativa (2024).
3. **Pestaña "Fuentes de datos"**: selector ahora incluye INEGI.
4. **13 tests** en `tests/test_inegi.py`.
5. **Total: 136 tests** en verde.

## Decisiones
- **URL corregida**: la documentación de INEGI usa `BIE-BISE/2.0`, no `BISE/2.0`.
- **Parser tolerante**: `OBSERVATIONS` en inglés, `COBER_GEO` para entidad.
- **Filtro por entidad siempre**: `entidad="0"` debe devolver solo la fila
  Nacional, no las 33 (Nacional + 32 estados).
- **Tests actualizados**: los tests viejos usaban `1002000001` y `OBSERVACIONES`
  (español), que ya no existen en la API.

## Lecciones
- **La API de INEGI es distinta a World Bank/Banxico**: formato propio,
  parámetros distintos, respuestas anidadas.
- **Probar con `curl` antes de asumir**: el primer intento falló por token
  mal puesto, no por URL.
- **El CI es tu red de seguridad**: los tests viejos fallaron en Linux
  porque no se actualizaron al nuevo formato.
- **Siempre `git status` antes de push**: si un archivo nuevo no se commitea,
  el CI falla aunque en local funcione.
- **Los tests con mock no siempre cubren casos reales**: el bug de
  `entidad="0"` no lo detectaron los tests, sino la prueba real (33 filas).
