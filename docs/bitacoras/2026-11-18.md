## Decisiones

- **OpenAlex ahora requiere API key gratuita** para búsquedas ininterrumpidas. La key se lee de `secrets.toml` con fallback a variable de entorno. Sin key, OpenAlex pausa las búsquedas anónimas por sobrecarga.
- **`mailto` configurable** vía `OPENALEX_EMAIL` para el "polite pool".
- **Cache de IA en `asistente_literatura.py`** con `@st.cache_data(ttl=86400)`. Si 5 alumnos buscan lo mismo, Gemini se llama 1 vez.
- **Timeout de 30s en Gemini** para evitar que la terminal se cuelgue (lección de ayer).
- **Bloque duplicado de "Fuentes de datos" eliminado**: ahora solo hay un botón "Consultar".

## Lecciones aprendidas

- **OpenAlex pausa búsquedas anónimas** cuando su clúster está sobrecargado. La API key gratuita es la solución.
- **`@st.cache_data` en `asistente_literatura.py`** rompió los tests porque Streamlit no estaba importado. Solución: importar `streamlit` y separar cache en un módulo aparte si se quiere mantener la lógica pura.
- **Los bloques duplicados en `app.py`** son deuda técnica que confunde. Mejor modularizar desde temprano (`app/seccion_*.py`).
- **Probar la API con `curl`** antes de culpar al código. El 503 era de OpenAlex, no nuestro.
